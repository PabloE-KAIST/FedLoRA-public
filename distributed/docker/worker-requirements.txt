# Worker container pip requirements (Milestone 1).

# NOTE: torch / torchvision / torchaudio are intentionally NOT listed here.
# The worker base image is expected to be an NVIDIA L4T PyTorch image for
# the target Jetson device class (e.g. nvcr.io/nvidia/l4t-pytorch:...),
# which already provides a CUDA-compatible torch build. Installing torch
# via pip here would either fail on arm64 or clobber the device-class
# build. All other runtime dependencies must be explicit.
#
# FedLoRA itself is NOT pip-installed inside the image. The repo is copied
# into /workspace/FedLoRA and made importable via PYTHONPATH. This matches
# the v2.3 rule that the worker is a thin wrapper and must not drift from
# the repo's import path.
